# Development Instructions

## Jekyll Installation
-------------------------------
  
  https://jekyllrb.com/docs/installation/

## Dev Deployment
--------------------------------

  npm install 
  gem install bundler
  bundle install
  bundle exec jekyll serve --livereload --force_polling

## Build Instructions
-------------------------------
  
  JEKYLL_ENV=production bundle exec jekyll build
